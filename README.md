# VINF — Project Gutenberg + Wikipedia search

Information retrieval project (FIIT STU, VINF 2026). Crawls Project Gutenberg,
extracts book metadata with regular expressions, joins it with a Wikipedia
dump using Apache Spark and searches it with an own full-text index.

## Structure

| Path | What it does |
|---|---|
| `main.py` | menu that runs everything (see below) |
| `crawler.py`, `fetcher.py` | Part 1: download HTML pages and plain texts |
| `extractor.py`, `test_extractor.py` | Part 1: regex metadata extraction + unit tests |
| `indexer.py`, `searcher.py` | Part 1: own inverted index, two weightings (`tfidf`, `sublinear`), cosine, boolean filter |
| `spark/` | Part 2: Spark extractor, Wikipedia dump parser, join, statistics, JSON export |
| `index2/` | Part 3: own fielded index (fields, phrase, fuzzy, range, boolean) |

## Requirements

* Python 3.10+ and Java (for Spark)
* `pip install pyspark`
* `pip install requests` (crawler); `pip install tiktoken` is optional (token statistics)
* no database, no BeautifulSoup, no pandas — only `re` and the standard library for parsing and indexing

## Data (not in the repository)

* `gutenberg_data/` — crawled HTML/TXT files (created by menu 1, 2)
* `wiki_data/enwiki_full.xml` — English Wikipedia dump (download separately)
* `spark_output/`, `index2_output/` — generated by the menu items below

## Run order

Run `python main.py` from the project root.

| Menu | Step |
|---|---|
| 1, 2, 3 | crawl, fetch texts, extract metadata to `gutenberg.tsv` |
| 4, 8 | Part 1 index and search |
| 10, 11, 12 | Spark: extract books, parse Wikipedia dump, join |
| 15 | Spark export: `joined.parquet` -> JSON lines |
| 16 | build the fielded index |
| 17 | search the fielded index |
| 18 | compare old index vs new index (`index2_output/comparison.txt`) |
| 19 | fielded index statistics |

## Query syntax of the fielded index

```
whale                      term in all default fields
title:whale  author:poe    term in one field
"great expectations"       phrase
title:whal*                prefix
title:frankenstien~2       fuzzy (max 2 edits)
pub_year:[1850 TO 1900]    numeric range ('*' = open end)
a AND b | a OR b | NOT a   boolean, also +a -a and ( )
title:whale^3              boost
```

Fields: `title, author, subjects, loc_class, abstract, categories, publisher,
genre, language, has_wiki, pub_year, release_year, downloads`.

## Scoring

No probabilistic idf. Part 1: `tf * log10(N/df)` and `(1 + log10(tf)) * log10(1 + N/df)`
with cosine similarity. Fielded index:
`(1 + log10(tf)) * log10(1 + N_field/df) * field_boost / sqrt(field_length)`.
